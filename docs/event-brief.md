# Event brief — Open Agent Hackathon 2026

Reference facts for this build. Sources: the participant event calendar supplied by
the organisers, plus the public GenAI Works pages.

- Event: https://hackathon.genai.works/event/open-agent-hackathon-2026
- Course: https://academy.genai.works/courses/open-agent-hackathon-2026/details
- **Official source of updates: the Announcements area on HackOS.** Check daily.

## Format

- Fully online. Teams of 1–5. Solo entry confirmed for this repo.
- Free. Open worldwide, age 16+ at the start of the build window.
- Every participant or team picks exactly one track.

## Tracks

1. **Connected Agent Context** — access relevant information, understand context and
   relationships across fragmented data.
2. **Autonomous Agent** — reason across multiple steps and act without hand-holding.
3. **The Agent That Can Explain Why** — maintain context and explain how it reached
   an answer.
4. **Reasoning Architecture** — the reasoning design itself.

Plus the **Tinkerer Track**, judged only on new work built during the window.
Scope unconfirmed from the official source — verify on HackOS.

## Scoring

| Criterion | Points |
|---|---:|
| Impact | 30 |
| Technical | 20 |
| Innovation | 15 |
| Demo | 15 |
| Product & UX | 10 |
| Sponsor tech | 10 |
| **Total** | **100** |

**Plus up to 30 bonus points** for open-sourcing, shipping evaluations, or documenting
insights. That is close to a third of the base score, and it is the part most solo
builders skip.

Prizes: $8,000 grand prize · $4,000 runner-up · $2,000 third place · pool up to $20,000.

## Submission must contain

- Project details: name, description, team members, selected track
- Links: GitHub repo, live demo, Google Drive where relevant
- Demo video showing how the product works
- Explanation: problem, solution, technologies used, sponsor technology where applicable

## Final preparation checklist (from the organisers)

- [ ] Runs from a clean setup with no manual steps
- [ ] Credentials load from environment variables only
- [ ] No API keys or secrets committed
- [ ] Logs show how the agent worked
- [ ] README setup steps complete
- [ ] Demo video recorded and ready to upload
- [ ] Sample inputs and outputs included
- [ ] Documented where each sponsor technology fits

## Mid-build checkpoint

Halfway (17 Oct), ask: *"If the submission deadline were tomorrow, what would fail?"*
Prioritise fixes from the answer.
